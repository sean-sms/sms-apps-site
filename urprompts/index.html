    Features

    Plain files. Fast recall.

    Everything lives in a folder you own, in a format you can read without this app ever being installed again.

    ☰

    Plain Markdown files

    One file per prompt, in a folder you choose. No database and no export button to hunt for. The folder doubles as an Obsidian vault if you'd rather edit prompts there.

    ⌕

    Search that keeps up

    Title, body, tags and trigger codes, ranked as you type, with the prompts you use most weighted higher.

    ✎

    Fill-in blanks

    Leave blanks for the parts that change — audience, tone, the document you're working on — and fill them when you recall it. Your last answers come back next time.

    ★

    Tags, favorites, models

    Tag by topic, star the ones you reach for daily, and note which models a prompt was written against.

    ⇆

    Sync through your own repo

    Point it at a private GitHub repository and it syncs over Git. If two machines change the same prompt, both versions are kept — nothing is quietly merged.

    ⌨

    Recall from anywhere

    A system-wide shortcut, Raycast commands, and an Espanso file so a trigger code expands into the full prompt in any text field — on Windows too.

    ✉

    Share a prompt, or a set

    Email a prompt with a description of what it does, hand another UrPrompts user a file they can double-click, or copy a tidy block into Teams or Slack.

    ⊘

    Nothing phones home

    No account, no analytics, no server. The only connection the app makes is the Git sync to a repository you chose.

    Privacy

    What never leaves your Mac.

    A shared prompt carries its text, description, tags, trigger code and fill-in blanks. That's all it carries.

    Most of this isn't in the prompt file to begin with — it's kept separately, per device, and sharing never reads it.

    • How often you've used a prompt, and when you last did.
    • The values you last typed into a prompt's blanks — whatever was last pasted in stays behind.
    • Which prompts you've marked as favorites.
    • Where a prompt sits in your own folders.
    • Your library's location, and the repository you sync it with.

    Install

    Four steps, once.

    1. Download the app and drag UrPrompts.app into your Applications folder.
    2. Right-click it and choose Open the first time, then confirm. macOS blocks a plain double-click because this app isn't signed with a paid Apple developer certificate; right-clicking is how you tell macOS you meant it. You only do this once.
    3. Pick a folder for your prompts. Anywhere you like. Each prompt becomes a Markdown file in it.
    4. Optional: connect a private GitHub repository to sync between machines. The app refuses to sync with a public repository, so your prompts can't be published by accident.

    The first build isn't published yet. Once it's on GitHub, the Download buttons on this page will point straight at it.
