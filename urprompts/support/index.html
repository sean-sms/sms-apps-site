UrPrompts support

Write to support@sms-apps.com with questions, problems or ideas. Please include your UrPrompts version (UrPrompts → About UrPrompts) and your macOS version. A real person reads every message.

UrPrompts runs on macOS 14 or later.

Common questions

How do I find and copy a prompt?

Press ⌘K, type a few letters of its title, tags or trigger code, and press Return. The prompt is copied, ready to paste into any AI app. From another app, ⌥⌘K opens the same search over whatever you're working in.

What are fill-in blanks?

Write {audience} anywhere in a prompt. When you copy it, UrPrompts asks for each blank and remembers what you typed last time. Add a note after a bar to explain a blank: {audience | who the piece is for}.

How do I sync between Macs?

Create an empty private repository on GitHub and a fine-grained token for it, then add both in Settings (⌘,). The step-by-step sync guide walks through it. UrPrompts refuses to sync with a public repository.

What happens if two Macs change the same prompt?

Neither version is lost and the two are never blended. The Mac that syncs keeps its version; the other one is saved beside it, and Conflicts in the sidebar lets you keep either one, or both as separate prompts.

Can I use trigger codes in any app?

Yes, with Espanso, a free text expander. Choose Library → Install Espanso File. The first time, UrPrompts asks you to choose Espanso's match folder (usually ~/Library/Application Support/espanso/match) and then keeps the file there up to date. Type ; and a trigger code in any app to expand the prompt.

Can I edit prompts in another app?

Yes. Each prompt is a Markdown file in your library folder, so Obsidian or any text editor can open it. UrPrompts reloads when you switch back to it; press ⌘R to reload by hand.

How do I share a prompt?

Select it and choose Share… (⌥⌘S). Copy for Chat and Copy as Email work in any app. For another UrPrompts user, send a .urprompts file: they double-click it and see what's in it before anything is added.

Removing UrPrompts and its data

Your prompts are yours: they stay in your library folder until you delete them. To remove the app's own data too, quit UrPrompts, then in Finder choose Go → Go to Folder… and move this to the Trash:

  • ~/Library/Containers/com.urprompts.app — settings and sync status (the App Store version)
  • ~/Library/Application Support/PromptLibrary — the same, for the version downloaded from this site

If you added a GitHub token, open Keychain Access and delete the item named com.promptlibrary.github. Use counts live in the .promptlib folder inside your library.
